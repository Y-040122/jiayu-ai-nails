# 甲遇 · AI 美甲服务原型

从一张美甲灵感图，到款式需求整理、AI 试戴、预估报价与预约安排的双端交互原型。

**在线体验**：https://jiayu-ai-nails.jiayu-studio.workers.dev/demo/index.html

> 在线版普通访客无需体验码；商家管理使用有权限的账号密码登录。共享演示空间，请不要提交真实顾客联系方式。独立 Cloudflare 版本需要重新配置 AI Secret，AI 可用性以实际验证为准。

## 核心功能

- 用户端：真实美甲图库、风格与色系筛选、价格排序、收藏、图片上传、可编辑款式方案。
- 真实 AI 接口：火山方舟豆包视觉解析、Seedream 双图试戴；未配置时明确报错，不以固定结果冒充识别。
- 自选款式也可手动填需求并预约，不依赖 AI 成功。
- 报价：基础服务、工艺与装饰加项，实时累计价格和耗时，最终由商家确认。
- 预约：选择美甲师和时间，按完整服务时长检查冲突。
- 商家端：工作台、款式上/下架、报价确认、排班调整、取消与完成预约。
- 图片输入：最大20MB原图，本机压缩；相册用途确认、摄像头拍照、手机布局。

## 目录与运行

`local/`：无前端构建依赖的 HTML/CSS/JavaScript 原型，Python 标准库服务端，业务数据保存在当前浏览器 localStorage。

```sh
cd local
python3 start_ai.py
```

按终端提示安全输入火山方舟 API Key，然后打开 http://127.0.0.1:4173/ 。输入不显示，密钥只进入当前进程环境。需要账号开通对应视觉与图像模型。

不调用AI时也可运行 `python3 server.py` 体验选款、手动方案与预约。支付、短信、复杂登录均未接入。

`cloud/`：Sites/Vinext 云端版本，含 D1 迁移、服务端体验码会话、商家权限、云端保存、乐观并发检查与每日共享20次AI调用上限。托管环境变量通过平台密钥设置配置，不提交到源码。

云端是**共享演示空间**，不是独立顾客账户系统。尚不适合直接承载真实门店业务；错误返回、冲突处理和接口调用均需持续实测。AI 试戴可能改变甲缘或饰品细节，不保证实物还原。

### 用户账号

用户可通过页面右上角“登录 / 注册”创建用户名和密码账号。游客可以浏览，收藏、保存方案和提交预约需要登录。账号的预约、收藏和方案按用户隔离；其他用户的占用时段仅返回排班信息。密码使用独立盐值及 PBKDF2-SHA256 哈希，登录 Cookie 为 HttpOnly、Secure、SameSite=Strict，有效期 2 天。当前不支持短信、邮箱验证及找回密码。

升级部署前执行 Cloudflare D1 数据库迁移 `wrangler d1 migrations apply jiayu-demo --remote`，再发布 Worker。旧共享演示预约保留在商家端，不自动归属任何新账号。

### 我的账户与主题

登录后点击右上角“我的账户”，可查看预约、收藏、已保存方案及最近浏览，修改显示昵称并切换深蓝夜间模式。登录用户名不区分大小写，显示昵称保留大小写。已保存方案随账号保存到云端；最近浏览记录与主题偏好保存在当前设备。

个人资料支持修改昵称、上传与移除头像。头像可选择 JPG / PNG / WebP（最大 10MB），浏览器居中裁剪并压缩至 256×256 JPEG，保存后随账号云端保留。

### 手机试戴稳定性

AI 试戴通过 Cloudflare Workflows 后台执行，网页仅提交任务并轮询状态。每个任务有唯一编号，重试提交和刷新查询不会重复调用生成模型。付费生成步骤关闭自动重试；模型超时或失败由用户主动重试。输入照片在本机进一步压缩，本次照片保留在标签页会话中；任务及结果可在24小时内恢复查询，任务输入在结束时清除。效果图经本站接口加载，可单独重新加载图片。

部署前应用 `0004_tryon_jobs.sql` 数据库迁移，并使用示例配置中的 `TRYON_WORKFLOW` 绑定。实现参考 [Cloudflare Workflows 文档](https://developers.cloudflare.com/workflows/)。

### 商家账号登录

当前 Cloudflare 版不再使用商家邀请码。访问 `/demo/?merchant=1`，使用已开通商家权限的普通账号密码登录；已登录的商家账号可直接进入。`accounts.is_merchant` 由服务端配置，不能在注册请求中自行授予。返回用户端后恢复个人记录视图。旧邀请码登录和旧商家会话已停止使用。初始页面只显示加载提示，避免加载时闪现旧登录界面。

### 双入口主页（当前流程）

打开 `/demo/` 或网站根地址先显示身份主页。消费者入口 `/demo/?consumer=1`：未登录进入登录/注册，已登录自动进入，Cookie 和服务端登录有效期为48小时。返回主页不会退出账号。商家入口 `/demo/?merchant=1` 直接打开演示工作台，不需要商家账号、管理码或邀请码。两端都有返回主页入口。

免登录商家与消费者的预约、款式和排班在同一浏览器的独立演示空间内同步；不同演示空间互相隔离。旧的共享空间预约保留在原数据库记录中，不向免登录商家展示。个人收藏和方案按账号保存。业务演示请勿使用真实顾客联系方式。此前的商家账号权限模式已被本流程替代。
