# 甲遇 · AI 美甲服务原型

从一张美甲灵感图，到款式需求整理、AI 试戴、预估报价与预约安排的双端交互原型。

**在线体验**：https://jiayu-nail-invite.daringcrumb10.chatgpt.site/demo/index.html

> 在线版普通访客无需体验码；商家管理保留验证。共享演示空间，请不要提交真实顾客联系方式。在线 AI 需要托管端单独配置密钥；不能把本地配置成功等同于线上可用。

## 核心功能

- 用户端：真实美甲图库、风格与色系筛选、价格排序、收藏、图片上传、可编辑款式方案。
- 真实 AI 接口：火山方舟豆包视觉解析、Seedream 双图试戴；未配置时明确报错，不以固定结果冒充识别。
- 自选款式也可手动填需求并预约，不依赖 AI 成功。
- 报价：基础服务、工艺与装饰加项，实时累计价格和耗时，最终由商家确认。
- 预约：选择美甲师和时间，按完整服务时长检查冲突。
- 商家端：工作台、款式上/下架、报价确认、排班调整、取消与完成预约。
- 图片输入：最大20MB原图，本机压缩；相册用途确认、摄像头拍照、手机布局。

## 目录与运行

`local/`：无前端构建依赖的 HTML/CSS/JavaScript 原型，Python 标准库服务端，业务数据保存在当前浏览器 localStorage。

```sh
cd local
python3 start_ai.py
```

按终端提示安全输入火山方舟 API Key，然后打开 http://127.0.0.1:4173/ 。输入不显示，密钥只进入当前进程环境。需要账号开通对应视觉与图像模型。

不调用AI时也可运行 `python3 server.py` 体验选款、手动方案与预约。支付、短信、复杂登录均未接入。

`cloud/`：Sites/Vinext 云端版本，含 D1 迁移、服务端体验码会话、商家权限、云端保存、乐观并发检查与每日共享20次AI调用上限。托管环境变量通过平台密钥设置配置，不提交到源码。

云端是**共享演示空间**，不是独立顾客账户系统。尚不适合直接承载真实门店业务；错误返回、冲突处理和接口调用均需持续实测。AI 试戴可能改变甲缘或饰品细节，不保证实物还原。
